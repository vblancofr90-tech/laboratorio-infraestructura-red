# Laboratorio de infraestructura de red empresarial

Proyecto personal: despliegue completo de una infraestructura de sistemas (Windows Server + Linux) sobre VMware Workstation, con Active Directory multi-DC, integración de clientes Linux, almacenamiento redundante, centralización de logs, contenedores, monitorización, backups y automatización.

**Documentación completa:** ver `Memoria_Proyecto_Infraestructura.docx` — 57 páginas con el desarrollo fase por fase, capturas, comandos utilizados e incidencias reales encontradas y su diagnóstico.

## Stack técnico

Windows Server 2022 · Active Directory (multi-DC, DNS, DHCP, GPO) · Ubuntu Server/Desktop · realmd/sssd · Samba (SMB) · NFS · OpenMediaVault · RAID 5 (mdadm) · Docker · Portainer · Prometheus · Grafana · Loki · rsyslog · PowerShell · Bash
